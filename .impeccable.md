## Design Context

### Users

React developers evaluate Digitloom before adopting it from npm. They compare motion, inspect customization, and reproduce integration examples.

### Brand Personality

Minimal, precise, restrained. The interface should inspire confidence through clear controls and accurate claims.

### Aesthetic Direction

Use a light theme, restrained colors, generous whitespace, and clear typography. Avoid decorative effects that compete with the digit animation.

### Design Principles

1. Make motion the focal point.
2. Keep customization controls clear and accessible.
3. Distinguish library weight from demo and React weight.
4. State performance limits beside stress controls.
5. Preserve reduced-motion preferences and keyboard access.
